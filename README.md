# 鹈鹕骑自行车 2D SVG 动画 (Pelican Riding Bicycle)

一个基于纯原生 HTML5 + SVG + CSS3 + 骨骼逆运动学（IK）实现的卡通动画演示。

## 🌟 特性

- **纯矢量 SVG 绘制**：高清无损缩放，包含鹈鹕骑手、复古自行车、车前置物篮（含蹦跳小鱼）、后轮尘埃与视差滚动背景。
- **双关节逆运动学 (2D IK)**：实时计算鹈鹕腿部髋关节到旋转脚踏板的膝盖位置，实现严丝合缝的踩踏动画。
- **生动的细节与次级动画**：
  - 巨大弹力喉囊（迎风弹性伸缩）
  - 反戴骑行遮阳帽与随风飞扬的红色波点围巾
  - 灵动的眼睛眨动
- **交互控制面板**：
  - 支持 **0.3x ~ 2.4x** 无级变速巡航
  - **白昼 / 黄昏 / 黑夜** 场景模式一键切换
  - 基于 Web Audio API 的自行车清脆铃声与鹈鹕音效

## 🚀 运行方式

直接在任何现代浏览器中双击打开 `index.html` 即可畅玩体验。
